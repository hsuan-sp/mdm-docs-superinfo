**VPP (大量採購方案) Token 是 Jamf Pro 與 Apple 校務管理 (ASM) 之間同步 App 與書籍授權的加密橋樑，必須每年手動更新一次。**

當 Token 過期時，Jamf Pro 將無法從 ASM 取得最新的授權狀態，導致新購買的 App 無法派送、也無法回收授權，嚴重影響教學現場的軟體部署。

## 過期前的警告機制：

- Jamf Pro 儀表板會顯示紅色或橘色的到期警告標籤。
- 管理員信箱會收到到期通知（通常為到期前 30 天發送）。

## 更新流程：

### 步驟一：從 Apple 校務管理下載新 Token

1. 使用具備「管理員」或「內容經理」權限的帳號登入 [school.apple.com](https://school.apple.com)。
2. 點選左下角的 **[帳號名稱]**，進入 **[偏好設定]**。
3. 選擇 **[付款與帳單]** 分頁。
4. 找到 **[App 與書籍]** 區塊中的對應位置（Location，如「資訊中心」）。
5. 點選該位置旁邊的 **[下載]** 按鈕，將 `.vpptoken` 檔案儲存至電腦。

### 步驟二：上傳至 Jamf Pro

1. 登入 Jamf Pro 管理介面。
2. 前往 **[設定]** > **[全域管理]** > **[大量採購]**。
3. 點選對應的位置 (Location) 項目進入詳細畫面，然後點選右下角的 **[編輯]**。
4. 點選 **[上傳]**，選擇剛才下載的 `.vpptoken` 檔案。
5. 點選 **[儲存]**。此時狀態應變更為「有效 (Active)」，且到期日會向後展延一年。

## 常見排錯：

- **位置 (Location) 錯誤**：若學校在 ASM 中建立了多個「位置」，每個位置都有獨立的 Token。上傳錯 Token 會導致授權數量瞬間歸零。
- **手動同步**：更新 Token 後，建議手動點擊一次 **[同步大量採購內容]**，確保軟體清單即時更新。

## 實務建議：

VPP Token 的年度展延是資訊組長的例行工作。建議將此任務排入每年暑假（7 月底）的「校園 IT 總體檢」待辦清單中，確保開學時所有教學 App 都能順利派發。
