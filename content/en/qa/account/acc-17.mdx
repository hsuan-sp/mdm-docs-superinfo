**The Platform SSO (PSSO) protocols introduced in macOS 15 have reached deep, native integration with FileVault in macOS 26 Tahoe, entirely eliminating the notoriously frustrating 'dual-password' friction point for educational deployments.**

In legacy domain-bound environments, even if a Mac was connected to an Active Directory or Entra ID, the initial FileVault pre-boot screen demanded a local disk password. Only after unlocking the disk could the OS connect to the network to authenticate the directory password. This frequently led to password desynchronization and high volumes of helpdesk tickets.

## The PSSO Solution and Operational Logic:

Platform SSO fundamentally alters the authentication chain:

1. **Low-Level Credential Synchronization**: Upon the user's initial network login, PSSO intercepts the credential exchange with the Identity Provider (IdP) and securely writes a cryptographic hash of that network password directly into FileVault's authorized unlock keychain.
2. **Seamless Passthrough Experience**: On subsequent reboots, the user encounters a single login screen where they input their school Google or Microsoft credentials. Once FileVault accepts the password and decrypts the drive, the identity token is passed seamlessly through to the macOS desktop environment.

## Technical Implementation Requirements:

- **OS Baseline**: macOS 15 is the absolute minimum, but upgrading fleets to **macOS 26 Tahoe** is highly recommended. Version 26 introduced vital optimizations for PSSO offline credential caching and network-drop fault tolerance.
- **IdP Compatibility**: Your school’s Identity Provider must support Apple's current PSSO API structure. Microsoft Entra ID and Okta provide native support, while Google Workspace supports it via specific extensions.
- **MDM Configuration via Jamf Pro**:
  1. Create a new "Single Sign-On Extensions" configuration profile.
  2. Set the payload type to **[Platform SSO]**.
  3. You must explicitly enable the **[Shared Device Keys]** and **[FileVault Integration]** toggles.

## Strategy: The Mac Deployment Blueprint

Schools deploying new Mac labs or administrative machines should mandate PSSO from day one. This architecture ensures complete institutional ownership (preventing users from locking down machines with local passwords) and centralizes all password reset requests within your Google or Microsoft admin console, drastically reducing IT overhead.
