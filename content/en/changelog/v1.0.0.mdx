### v1.0.0 — Initial Release

The Superinfo Apple MDM Knowledge Base is now available. This site provides structured reference resources for Apple device management in Taiwan's education and enterprise environments.

#### Feature Overview

**Site Architecture**

- Built with Next.js (App Router) and the Nextra documentation framework, supporting static generation and server-side rendering.
- Light and dark mode support, respecting system preferences.
- Bilingual interface (Traditional Chinese / English) with instant switching — no page reload required.

**Troubleshooting Guide**

- Q&A-style content covering eight knowledge domains: device deployment, account management, app distribution, classroom tools, Mac management, and more.
- Includes keyword search, chapter filtering, and adjustable font size.

**Glossary**

- Over 220 Apple MDM-related terms, each with a definition and a plain-language analogy.
- Supports category filtering, sorting, and real-time search.

**Page Issue Reporting**

- Each page includes a reporting feature that auto-populates a report template with page context.

#### Knowledge Domains

1. **Account & Server** — Apple School Manager, Managed Apple ID, Federated Authentication
2. **Device Deployment** — Apple Configurator, Automated Device Enrollment (ADE)
3. **Apps & Content** — Volume Purchase, license assignment and revocation
4. **Classroom Tools** — Apple Classroom, Schoolwork setup and usage
5. **Digital Learning Initiative** — Ministry of Education project specifications
6. **Service & Support** — Hardware repair workflow, warranty lookup, loaner management
7. **Mac Management** — Advanced macOS management, scripting, and security configuration
8. **Campus Q&A** — Common deployment issues and solutions
